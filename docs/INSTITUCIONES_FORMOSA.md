# Instituciones de nivel superior no universitario de Formosa

Revisión: 6 de noviembre de 2026.

Provincia de Formosa, sedes y anexos. No incluye universidades adicionales. Directorio público y oferta 2026; no es garantía de exhaustividad ni de inscripciones abiertas.

Se incorporan 49 sedes/anexos adicionales a IPF y UNaF. 24 tienen un catálogo parcial de carreras contrastado con el mapa oficial 2026. Las demás permiten registro con carrera pendiente, sin campos de carrera de texto libre.

No se afirma que el directorio sea exhaustivo ni que todas las instituciones conserven actualmente las mismas ofertas. No se agregan universidades a partir de una lista de terciarios. Los TTP cortos y postítulos se excluyen del selector de carreras iniciales. El mapa no ofrece carreras de formación docente inicial para la cohorte 2026: esto no permite inferir que no existan estudiantes de cohortes anteriores.
